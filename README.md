# 🌸 Цветочный Магазин Бот - Обновления

## ✅ Что было исправлено и добавлено:

### 1. **Команда `/list` - Просмотр товаров текстом**
- Добавлена новая команда `/list` в Telegram боте
- Показывает все доступные товары с ID, названием, ценой и описанием
- Кнопка для быстрого перехода в веб-магазин

### 2. **Динамическая загрузка товаров**
- Создан HTTP API сервер (порт 8080) для получения товаров
- Веб-интерфейс теперь динамически загружает товары вместо хардкода
- Товары загружаются при открытии магазина

### 3. **Улучшенная обработка платежей**
- ✅ Проверка наличия всех необходимых полей (ID товара, название, количество, цена)
- ✅ Валидация количества и цены (должны быть > 0)
- ❌ При ошибке - отправляется сообщение об ошибке
- 🔄 Кнопка "Вернуться в магазин" при ошибке
- 📝 Улучшенное оформление чека

### 4. **Команда удаления товара `/del`**
- Теперь с проверкой наличия товара перед удалением
- Выводит название удаленного товара
- Обработка ошибок с корректным сообщением

### 5. **Защита команд администратора**
- Добавлена проверка прав доступа для `/add` и `/del`
- Только администратор (из config.py) может добавлять/удалять товары

## 📋 Команды Telegram бота:

```
/start    - Главное меню с кнопкой магазина
/list     - Просмотр всех товаров текстом
/add <название> <цена> <описание>  - Добавить товар (только для админа)
/del <ID>  - Удалить товар по ID (только для админа)
```

## 🛠 Установка зависимостей:

```bash
pip install -r requirements.txt
```

## 🚀 Запуск:

```bash
python main.py
```

Бот запустится вместе с HTTP API сервером на портах:
- Telegram Bot Polling
- HTTP API на `http://localhost:8080/api/products`

## 📱 Данные, отправляемые при заказе:

```json
{
  "product_id": 1,
  "item": "Розы Red",
  "quantity": 5,
  "price": 6000
}
```

## 🔄 Процесс покупки:

1. Пользователь открывает магазин (`/start`)
2. Выбирает товар и количество
3. Нажимает "Купить"
4. **Проверка**: Отправляются ли все данные (ID, название, кол-во, цена)?
   - ✅ ДА → Формируется чек, пользователь переводит деньги
   - ❌ НЕТ → Ошибка + кнопка "Вернуться в магазин"
5. После оплаты пользователь отправляет скриншот чека

## 📁 Структура файлов:

- `main.py` - Главный файл бота + HTTP API сервер
- `handlers.py` - Обработчики команд и событий
- `database.py` - Работа с БД (SQLite)
- `config.py` - Конфигурация (токен, ID админа и т.д.)
- `index.html` - Веб-интерфейс магазина
- `script.js` - Логика загрузки товаров и оформления заказа
- `style.css` - Стили веб-интерфейса
- `requirements.txt` - Зависимости Python
